# Política de privacidade — GarraTV

_Última atualização: 29 de outubro de 2026_

O GarraTV é um reprodutor de IPTV. Ele **não fornece canais, filmes nem séries**:
o conteúdo vem da conta Xtream Codes que o próprio usuário informa, ou de listas
públicas de canais abertos (comunidade iptv-org).

## Dados que o app guarda

- **Dados de acesso do provedor** (endereço do servidor, usuário e senha):
  ficam salvos **somente no aparelho**, para o app conseguir se conectar ao
  provedor escolhido pelo usuário.
- **Perfis, favoritos e progresso de reprodução**: salvos **somente no aparelho**.
- **Preferências** (idioma, país dos canais grátis): salvas no aparelho.

## Dados que o app envia

- O app se comunica **apenas** com o servidor do provedor informado pelo
  usuário, com as listas públicas de canais grátis e, se configurado pelo
  usuário, com os serviços TMDB (capas e sinopses) e OpenSubtitles (legendas).
- O GarraTV **não tem servidor próprio**, não coleta estatísticas, não exibe
  anúncios e não compartilha dados com terceiros.

## Exclusão dos dados

Sair da conta nas Configurações apaga os dados de acesso. Desinstalar o app
remove todos os dados salvos no aparelho.
